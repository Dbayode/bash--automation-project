# Bash Automation Project

## Overview

This project demonstrates automation using Bash scripting.

## Tasks Completed

### Task 1
Automated directory and file creation using:
- mkdir -p
- touch
- echo
- timestamps

### Task 2
System monitoring using:
- df
- free
- conditionals
- exit codes

### Task 3
Modular scripting using:
- functions
- sourcing
- local variables

### Task 4
Input validation using:
- set -e
- set -u
- pipefail
- trap
